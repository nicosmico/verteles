# Verteles

Reproductor de TV en vivo (IPTV) liviano para televisores Samsung (Tizen) y LG (webOS), con versión web y, más adelante, Android TV. Funciona solo en el cliente: agregas Listas M3U y la app las reproduce. No hay servidor propio.

> **Estado:** en reescritura. La versión anterior está en el commit `b879f95` de `main`.

- [`docs/roadmap.md`](docs/roadmap.md): fases y modelo de control remoto.
- [`docs/adr/`](docs/adr): decisiones de arquitectura.
- [`docs/specs/`](docs/specs) y [`docs/tickets/`](docs/tickets): trabajo de cada fase.

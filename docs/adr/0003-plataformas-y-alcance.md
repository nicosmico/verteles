# Plataformas, orden y alcance

Las plataformas se agregan en orden de dificultad: **Web → Tizen → webOS → Android TV**. La web es la plataforma más fácil para desarrollar y testear, pero toda decisión se toma pensando en que el objetivo real es Tizen en un televisor de bajos recursos. Android TV llega en una fase posterior mediante un wrapper nativo.

Fuera de alcance: Chromecast, AirPlay y cualquier backend propio. La app es 100% cliente.
